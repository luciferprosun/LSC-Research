# Draft: Minimal GALLEX/GNO Data Request

This is a draft only. It was not sent.

Subject: Request for GALLEX chromium source-run likelihood/covariance metadata

Could the following numerical objects for the Cr1 and Cr2 source campaigns be shared or pointed to:

1. Source-run covariance or the likelihood object used for the published source results.
2. Correlation definitions for calibration, extraction, counting, and source activity.
3. Exact exposure intervals with timezone/UTC convention.
4. Any authoritative machine-readable source/target geometry used to obtain the published geometry factors.

These objects would unlock preregistered cross-experiment and run-level validation. Preferred formats are CSV/JSON/ROOT with release/version metadata.

We understand that unpublished material may not be distributable.
