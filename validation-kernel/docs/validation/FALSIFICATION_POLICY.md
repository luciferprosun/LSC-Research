# Falsification policy

The machine registry separates three levels:

- test-level falsification: a frozen prediction fails one preregistered test;
- component-level falsification: a transfer, isotope, directional or mapped external component fails;
- model-level falsification: an equally or less complex baseline predicts held-out data equally well or better under the frozen comparison rule.

Support is weakened when apparent advantage disappears across credible preregistered covariance/nuisance scenarios. It is also weakened or falsified at the applicable level when required experiment/isotope transfer fails, or a valid preregistered external mapping excludes a required region.

No single test failure automatically becomes global model falsification unless a pre-result escalation rule explicitly says so. Conversely, blocked, missing or underpowered data are never converted into a PASS. Negative, null, adverse and blocked outcomes are mandatory report items.

Directional claims can be adjudicated only by a future adequately powered T12 with authentic timing, surveyed orientation, geometry, tensor, frames and units. Present inability to run T12 is neither confirmation nor falsification.
