# LSC Research

Standalone scientific repository for the LSC research line.

## Authority

This repository is physics-first and neutrino-focused. It exists to preserve and continue:
- neutrino phenomenology
- BEST/Gallium analysis
- detector and systematics work
- validation frameworks
- simulation tooling tied to physics
- scientific papers, datasets, and reproducibility artifacts

This repository is not an MHLM/MDLH or AOIA authority root.

## Structure

- `LSC_core/`: extracted LSC scientific corpus
- `framework/`: datasets, loaders, likelihoods, baselines, notebooks, and tests
- `legacy/`: preserved scientific lineage imports
- `reports/`: physics-side reports preserved during extraction
- `docs/`: repository-level scope, lineage, and history continuation planning

## Exclusions

The following were intentionally kept out of this repository:
- hallucination framing
- AI safety interpretation
- recursive cognition analysis
- runtime governance analysis
- AOIA runtime systems
