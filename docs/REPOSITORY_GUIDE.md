# Repository Guide

This repository is organized as a freeze-stage scientific archive.

Start with:

1. `README.md`
2. `canonical/LSC_CANONICAL_CORE.md`
3. `canonical/LSC_FREEZE_BOUNDARY.md`
4. `validation/LSC_VALIDATION_PROTOCOL.md`
5. `implementation/LSC_DATA_REQUIREMENT_MATRIX.md`
6. `freeze_release/FINAL_GITHUB_FREEZE_CHECKLIST.md`

Historical and deprecated materials are preserved under `historical_archive/`. They are not active LSC claims unless explicitly promoted in `canonical/`.
