# Draft: KATRIN Numerical Interface Clarification

This is a draft only. It was not sent.

The current KATRIN release is internally sufficient for its native sterile-neutrino grid. No additional data request is made.

If a future independently derived LSC-to-sterile mapping exists, the only clarification potentially needed would be confirmation of the intended use of the absolute chi-square map, treatment of capped/interpolated points, and which nuisance/profile assumptions must be preserved. No request should be sent before such a mapping is explicitly defined.
