# Draft: Minimal BEST Data Request

This is a draft only. It was not sent.

Subject: Request for numerical BEST covariance or likelihood object for reproducible source-experiment validation

We are preparing a provenance-preserving validation framework for fixed historical model predictions. We would be grateful to know whether the following BEST numerical objects can be shared:

1. The statistical and systematic covariance for the 10 inner plus 10 outer extraction results, including inner/outer cross-correlation.
2. The corresponding nuisance definitions or a joint likelihood/workspace, if that is the authoritative representation.
3. The source-activity, extraction, counting, and geometry correlation scopes used in that object.

These objects would unlock preregistered zone-transfer, run-level, and baseline-comparison tests. Preferred formats are CSV/JSON/ROOT with a field definition and release/version identifier.

We understand that unpublished collaboration material may not be distributable. A statement identifying the authoritative published approximation would also be useful.
