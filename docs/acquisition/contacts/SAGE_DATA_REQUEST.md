# Draft: Minimal SAGE Data Request

This is a draft only. It was not sent.

Subject: Request for SAGE source-run covariance and timing metadata

For reproducible fixed-model validation, could the following objects for the 51Cr and 37Ar source campaigns be shared or authoritatively identified:

1. Run-level covariance or likelihood and the source-calibration/extraction/counting correlation definitions.
2. Exact timezone/UTC interpretation of published exposure/reference times.
3. Any distributable surveyed detector/source orientation and machine-readable source/target geometry used for integration.

The covariance unlocks run and cross-isotope tests. Timing/orientation would only support a future separately preregistered directional readiness assessment. Preferred formats are CSV/JSON/ROOT plus version/provenance metadata.

We understand that unpublished data may not be shareable.
