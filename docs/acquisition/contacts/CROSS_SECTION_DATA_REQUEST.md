# Draft: Minimal Gallium Cross-Section Data Request

This is a draft only. It was not sent.

Subject: Request for joint gallium transition-strength covariance

For a preregistered 51Cr-to-37Ar sensitivity and validation analysis, could an authoritative numerical covariance or posterior sample be shared for the relevant ground/excited-state transition strengths and common nuclear systematics?

The critical object is the joint correlation structure across isotopes and model components, not additional marginal error bars. Preferred formats are CSV/JSON/NumPy with parameter order, units, source version, and a description of shared uncertainties.

We understand that only marginal uncertainties may be public and that unpublished numerical objects may not be shareable.
