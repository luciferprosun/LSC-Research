# LSC Freeze Boundary

Status: Step 1 canonicalization output  
Boundary: pre-BEST-2 freeze era  

## 1. What Is Frozen

The following are frozen:

- LSC status as an unvalidated phenomenological validation framework.
- LSC 6.3.0 as the current freeze state.
- Zenodo concept DOI `10.5281/zenodo.19780615` as primary identity.
- Trace/traceless detector-response separation.
- M0-M6 baseline hierarchy.
- Requirement that detector systematics remain an active competitor.
- Requirement that sterile-neutrino baselines remain active.
- Requirement for leave-one-out and cross-experiment validation.
- Requirement for covariance-aware model comparison.
- Requirement for quantitative external veto checks.
- Claim boundary: no discovery, no sterile exclusion, no confirmed tensor field.

## 2. What Is Not Frozen

The following are not frozen because they remain underdefined or data-blocked:

- exact functional forms for `f0_a(E,t)` and `fA_a(E,t)`;
- physically motivated tensor orientation;
- final parameter bounds;
- full detector-systematics baseline M4;
- full covariance model;
- KATRIN/IceCube/solar quantitative veto mapping;
- BEST-2 prediction values;
- sidereal modulation amplitude and phase.

These must not be retroactively fitted after BEST-2 data are seen.

## 3. Prohibited Future Extension Without New Data

Without new data or explicit preregistration, it is prohibited to:

- add new mechanisms;
- add new tensor structures;
- add new particle claims;
- revive PBH/curvature language as active core;
- reinterpret detector systematics as LSC evidence without M4 comparison;
- tune tensor orientation after data inspection;
- claim sidereal evidence without timestamps and detector orientation;
- claim statistical preference without full covariance or a clearly labeled exploratory approximation;
- treat AI audit agreement as physics evidence.

## 4. Allowed Claims

Allowed:

- LSC 6.3.0 is a conservative pre-BEST-2 validation framework.
- The framework tests trace and traceless detector-response templates against required baselines.
- Current public data are insufficient for full likelihood-level validation.
- Full covariance and metadata are required before strong claims.
- Negative results are valid freeze-era outcomes.

## 5. Not Allowed Claims

Not allowed:

- LSC explains the Gallium anomaly.
- LSC proves new physics.
- LSC excludes sterile neutrinos.
- LSC tensor parameters are confirmed physical fields.
- LSC has survived KATRIN/IceCube/solar vetoes unless explicitly computed.
- Anchor fits validate the theory.
- BEST-2 will confirm LSC.

## 6. Falsification or Weakening Conditions

LSC is weakened if:

- M4 detector-systematics baseline reproduces all LSC-like structures;
- M1/M2 normalization or cross-section nuisance models perform as well as M5/M6 after penalties;
- leave-one-out remains unstable;
- cross-experiment transfer fails;
- anisotropy collapses into scalar normalization under covariance propagation;
- each experiment requires unrelated tensor parameters;
- external vetoes exclude the required parameter region.

LSC requires major revision or abandonment if:

- frozen templates fail against BEST-2 while simpler baselines succeed;
- sidereal/orientation predictions fail where required metadata exist;
- the model cannot be distinguished from mundane detector effects;
- external vetoes are quantitatively incompatible with required amplitudes.

## 7. Structures Remaining Unresolved

Unresolved:

- physical origin of `delta_G` or equivalent effective response term;
- physical status of the anisotropy tensor;
- Lorentz-violation / SME mapping;
- KATRIN energy-response mapping;
- IceCube constraint mapping;
- detector-systematics M4 implementation;
- covariance access;
- BEST-2 metadata access;
- identifiability of trace vs traceless terms with realistic data.

## 8. Step 2 Requirements

Step 2 must not expand the theory. It must build validation infrastructure:

- define exact data requirements;
- create covariance placeholder policy;
- define M4 detector-systematics baseline specification;
- freeze `f0_a` and `fA_a` only if source-justified;
- define leave-one-out and cross-experiment validation protocol;
- define external veto calculation checklist;
- produce a preregistration-ready validation plan.
