# LSC Zenodo Release Notes Final Draft

## Release Title

LSC Pre-BEST-2 Freeze & Validation Framework

## Authors

- LuciferSun
- flAmeBorn

## Release Type

Conservative archival update and consolidation of the existing LSC 6.3.0 freeze-stage framework.

## Positioning

This release is not a discovery publication and not LSC 6.4. It preserves LSC as an unvalidated constrained phenomenological validation framework for Gallium/BEST-style neutrino anomaly analysis.

It does not claim:

- confirmed new physics;
- sterile-neutrino exclusion;
- solved anomaly;
- completed BEST-2 validation.

## What This Update Adds

- Finalized GitHub freeze repository structure.
- Canonical freeze documents.
- Validation infrastructure and M0-M6 model hierarchy.
- M4 detector/systematics primary competitor.
- Implementation templates for future validation work.
- Provenance manifests and checksums.
- Audit summaries and extracted criticism layers.
- Request-for-data materials.
- Updated authorship and metadata.

## Validation Discipline

The archive explicitly preserves:

- missing covariance as a blocker to full likelihood validation;
- M4 detector/systematics as a primary competitor;
- negative outcomes as valid outcomes;
- AI agreement as non-evidence;
- future BEST-2-era analysis as the relevant test environment.

## Publication Boundary

This release should be cited as a framework and validation archive, not as evidence that LSC is experimentally confirmed.
