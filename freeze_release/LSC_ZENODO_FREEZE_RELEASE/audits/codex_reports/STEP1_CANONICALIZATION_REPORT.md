# LSC Step 1 Canonicalization Report

Status: final Step 1 report  
Scope: canonicalization + structural cleanup only  

## Executive Summary

Step 1 reduces LSC to a constrained pre-BEST-2 phenomenological validation framework. No new mechanisms, new equations, new particles, LSC 6.4 material, MHLM/AOIA material, or discovery claims were introduced.

Canonicalized as active:

- LSC 6.3.0 freeze state;
- trace/traceless detector-response separation;
- M0-M6 baseline hierarchy;
- frozen prediction protocol;
- covariance-aware validation requirement;
- leave-one-out and cross-experiment validation;
- external veto requirements;
- strict claim boundary.

Deprecated or archived:

- PBH-heavy structures;
- curvature-heavy speculative mechanisms;
- explicit historical Hamiltonian/curvature forms as active Gallium core;
- Schwarzschild-style energy-map mechanism;
- unconstrained tensor freedom;
- LSC 5.5 covariant Lagrangian as current theory;
- anchor-fit validation claims;
- MHLM/MDLH/AOIA/AI-safety material.

## Canonicalization Decisions

1. LSC remains unvalidated phenomenology.
2. LSC 6.3.0 is the active freeze state.
3. The active target is Gallium/BEST residual validation, not broad neutrino theory completion.
4. Sterile-neutrino and detector-systematics explanations remain active competitors.
5. The tensor structure is retained only as a constrained detector-response template.
6. Directional/traceless claims are currently metadata-blocked.
7. Statistical claims are blocked without full covariance.
8. External vetoes are hard constraints, not optional discussion.
