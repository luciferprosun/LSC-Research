3.3 Dimensionally Unclear Equations
The following structures require dimensional review before freeze:

[DIM_REVIEW] delta_G(Phi, E)
Claimed to be dimensionless effective gravitational correction, but Phi has dimensions of energy/mass and E has
dimensions of energy. The ratio Phi/E is dimensionless, but the functional form G(Phi,E) = 1 + delta_G + O(delta_G^2)
requires delta_G itself to be dimensionless. The 6.0 document states 'natural solar-system gravitational effects are too
small to directly explain percent-level Gallium deficits,' implying delta_G is a phenomenological fit parameter rather than
a derived quantity. ACTION: Freeze with explicit note that delta_G is phenomenological effective parameter, not derived
from first principles.

[DIM_REVIEW] alpha_D * D_ij * p^i * p^j
alpha_D is dimensionless coupling; D_ij has dimensions of inverse energy squared (if from metric perturbation) or is
dimensionless (if from detector response tensor). The 6.3.0 protocol treats D_ij as detector-response tensor with implicit
energy scale set by cross-section energy dependence. ACTION: Define D_ij as dimensionless detector-response tensor
normalized to cross-section energy scale.

[DIM_REVIEW] A_munu n^mu n^nu
A_munu is traceless anisotropy tensor. If n^mu is unit vector, A_munu must have same dimensions as the quantity it
modifies (event rate or energy). In 6.3.0, A_munu appears inside epsilon_LSC which modifies event rate, making
A_munu dimensionless. ACTION: Explicitly define A_munu as dimensionless traceless tensor.

[DIM_REVIEW] lambda0, lambdaA
These are mixing parameters in 6.3.0 protocol. lambda0 controls isotropic LSC contribution; lambdaA controls
anisotropic. Their physical dimensions depend on what they multiply. In the protocol, they appear as dimensionless
multipliers of baseline rates. ACTION: Define as dimensionless relative coupling strengths.

5.3 The Leave-One-Out Problem
The 6.2.1 codex validation package explicitly demonstrates that exact anchor fits of BEST/GALLEX/SAGE ratios are
insufficient validation. Leave-one-out tests show instability. This is the strongest internal warning in the LSC framework

and must be treated as a hard blocker to any stronger claim.
AUDIT ASSESSMENT: The leave-one-out instability means the LSC parameterization is overfitting the available data.
Possible causes:
• Too many free parameters relative to independent data constraints (lambda0, lambdaA, A_munu, delta_G, D_iso = 5+
parameters for ~3 independent ratios)
• Strong parameter degeneracy between trace and traceless components when only total rates are measured
• Missing covariance structure leading to underestimated uncertainties
• Detector systematics absorbing what should be LSC signal (or vice versa)
RECOMMENDATION: Do not proceed to BEST-2 fitting until leave-one-out stability is achieved with current data, or until
BEST-2 provides sufficient additional constraints to break degeneracies.

6.1 Risk of Unfalsifiability
The LSC framework risks becoming unfalsifiable if the following conditions are not actively prevented:

[UNFALSIFIABILITY RISK] Detector Systematics Mimicry
If detector response variations (efficiency, geometry, extraction) can reproduce all claimed LSC anisotropy patterns, then
LSC is not distinguishable from systematics. The M4 baseline must be developed to quantitative competitiveness.

[UNFALSIFIABILITY RISK] Parameter Degeneracy
If lambda0 (trace) and lambdaA (traceless) are strongly degenerate given current data, then LSC cannot claim
anisotropy even if total rates are fit. The trace/traceless split must be validated with directional data.

[UNFALSIFIABILITY RISK] Post-Hoc Tuning
If BEST-2 predictions are adjusted after seeing data (not frozen beforehand), the framework loses falsifiability. The 6.3.0
freeze protocol is designed to prevent this but requires enforcement.

[UNFALSIFIABILITY RISK] Moving Goalposts
If external vetoes (KATRIN, IceCube, solar) are ignored or re-interpreted when they exclude parameter space, the
framework becomes unfalsifiable. Vetoes must be treated as hard constraints.

[UNFALSIFIABILITY RISK] Infinite Effective Parameters

If delta_G and A_munu can absorb any discrepancy without independent measurement, the framework loses predictive
power. These must be constrained by non-Gallium data or bounded by physics.

7.1 Minimal Conceptual Framework
The LSC pre-BEST-2 freeze core addresses one phenomenological question:

Can a detector-response model with scalar trace plus traceless anisotropic components structure
gallium-source residuals better than null, normalization-only, cross-section/systematics, sterile-neutrino,
or detector-systematics alternatives, while surviving external vetoes?
Key constraints on this question:
• The framework is explicitly unvalidated—not confirmed new physics.
• Sterile neutrinos remain required comparison baselines (M3), not eliminated assumptions.
• Anchor fits alone are insufficient; leave-one-out and cross-experiment validation are required.
• Detector systematics must remain active competitors (M4), not dismissed alternatives.
• External vetoes (KATRIN, IceCube, solar) must survive quantitatively, not qualitatively.
• All predictions must be frozen before BEST-2 data fitting (preregistration protocol).

8. SALVAGEABILITY AND OVERCOMPLICATION ANALYSIS
8.A Scientifically Salvageable Structures
[SALVAGEABLE] Trace/Traceless Decomposition
This is the cleanest structural element. It maps directly to observable quantities (scalar rate shifts vs directional
modulation) and has a clear falsification criterion. Even if LSC is wrong, this decomposition could be useful for detector
systematics characterization.

[SALVAGEABLE] Frozen Prediction Protocol
The preregistration methodology is scientifically valuable independent of LSC physics. It should be adopted as standard
practice for BSM phenomenology.

[SALVAGEABLE] Baseline Model Hierarchy (M0-M6)
The explicit comparison against null, normalization, systematics, and sterile baselines is methodologically correct. This
structure is salvageable even if LSC-specific content is abandoned.

[SALVAGEABLE] Cross-Experiment Transfer Framework
The concept of training on one experiment and predicting another without re-tuning is a strong validation test.
Methodologically valuable.

[SALVAGEABLE] Effective Parameter Framework
Treating delta_G as phenomenological rather than derived is scientifically conservative. This approach is salvageable as
a general BSM search strategy.

8.B Historical Lineage Only
[HISTORICAL] LSC 4.2 ULTRA
PBH/curvature language has no connection to current Gallium phenomenology. Preserve in archive for provenance only.

[HISTORICAL] Relativistic Energy Mapping (5.0@)
The E_obs vs E_emit distinction was a useful conceptual bridge but is not operationally defined. Historical lineage.

[HISTORICAL] Resonant Geometric Modulation (5.5)
Nonlinear tensor energy reconstruction language. Absorbed into effective parameters. Historical.

[HISTORICAL] Explicit H_vac, H_grav, H_matter Decomposition
The four-term Hamiltonian split was exploratory. Only H_matter (via V_matter) and effective H_LSC survived. Historical.

8.C Overcomplicated Structures
[OVERCOMPLICATED] 68-Equation Full Inventory
Massive redundancy. Many equations are parameter redefinitions, not independent physical statements. The freeze core
compresses to 15.

[OVERCOMPLICATED] Multiple Energy Reconstruction Formalisms

LSC 5.0@, 6.0, and 6.3.0 each define different energy reconstruction schemes. These should be unified into a single
effective framework.

[OVERCOMPLICATED] Redundant Anisotropy Parameterizations
D_munu, Delta_D_ij, A_munu, q_a, and S_a are related by linear transformations. The freeze core should use one
consistent parameterization (A_munu).

[OVERCOMPLICATED] Nested Hamiltonian Decomposition
H_eff = H_vac + H_matter + H_grav + H_LSC with each term having sub-decompositions. Overly complex for
phenomenological framework.

[OVERCOMPLICATED] Dual Repository Structure
The separation between LSC-Research and LLM-MHLM-Main-Project creates confusion. The scientific core should be in
one authority repository.

developed to full competitiveness.

frozen with specific functional forms.
