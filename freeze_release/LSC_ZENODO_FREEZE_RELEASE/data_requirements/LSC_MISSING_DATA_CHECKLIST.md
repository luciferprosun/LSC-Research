# LSC Missing Data Checklist

Status: generated from the source inventory and gallium dataset reports.

## Required for rigorous BEST/Gallium validation

- Full BEST extraction-by-extraction table.
- BEST zone-by-zone statistical and systematic covariance matrix.
- Counter efficiencies and exposure-cycle metadata.
- Exact GALLEX source coordinates for both insertions.
- GALLEX exposure-level event table and detector response covariance.
- SAGE run-by-run source exposure table.
- SAGE 37Ar impurity table and counter-level likelihood inputs.
- Unified BEST/GALLEX/SAGE machine-readable schema with uncertainty conventions.
- Sterile-neutrino baseline with dataset-accurate L/E mapping.
- Cross-section uncertainty propagation for 71Ga capture lines.
- KATRIN and IceCube constraints in machine-readable form for veto tests.
- Detector orientation, timestamps, and environmental monitoring for sidereal/orientation tests.

## Current status

The existing local dataset is sufficient for first-pass rate-ratio comparisons, but not for official likelihood reproduction or detector-systematics fitting.
