# LSC Zenodo Freeze Release Candidate

Title: LSC Pre-BEST-2 Freeze & Validation Framework  
Authors: LuciferSun; flAmeBorn  
Status: local Zenodo-ready package draft; not uploaded  

## Purpose

This folder is a local release-candidate package for a future Zenodo archival snapshot of the LSC 6.3.0 Pre-BEST-2 freeze-stage framework.

It is not a publication action. It is not a GitHub release. It is not a Zenodo upload.

## Claim Boundary

The package presents LSC as an unvalidated constrained phenomenological validation framework.

It does not claim:

- confirmed new physics;
- sterile-neutrino exclusion;
- solved Gallium/BEST anomaly;
- validated BEST-2 prediction;
- AI agreement as scientific evidence.
