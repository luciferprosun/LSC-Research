# Final Freeze Review Checklist

## Publication Gate

This checklist must be completed before any GitHub release, Zenodo upload, arXiv preparation, or public freeze announcement.

## Theory Boundary

| Check | Status before release |
|---|---|
| No theory expansion occurred during STEP 4. | Required |
| No new equations were introduced. | Required |
| No hidden tensor extensions were introduced. | Required |
| No new particle claim was introduced. | Required |
| No LSC 6.4 or post-freeze version was created. | Required |
| Speculative material remains separated from canonical core. | Required |

## Claim Boundary

| Prohibited claim | Must be absent |
|---|---|
| Confirmed new physics. | Yes |
| Sterile-neutrino exclusion. | Yes |
| Detector/systematics exclusion. | Yes |
| BEST-2 prediction already validated. | Yes |
| AI consensus as evidence. | Yes |

## Placeholder Discipline

| Check | Status before release |
|---|---|
| Covariance placeholders marked non-validation-grade. | Required |
| Missing data clearly listed. | Required |
| M4 detector/systematics competitor preserved as primary competitor. | Required |
| Negative outcomes remain valid outcomes. | Required |
| Publication claims limited to framework/readiness status. | Required |

## Provenance and Reproducibility

| Check | Status before release |
|---|---|
| Source/provenance manifest generated. | Required |
| Checksums generated. | Required |
| External audit originals included or referenced. | Required |
| Extracted audit text included. | Required |
| Canonical source inventory included. | Required |
| Zenodo metadata draft reviewed manually. | Required |
| License and authorship verified manually. | Required |

## Validation Readiness

| Check | Status |
|---|---|
| M0-M6 hierarchy included. | Required |
| M4 implementation schema included. | Required |
| External veto checklist included. | Required |
| BEST-2 preregistration form included. | Required |
| Data request package included. | Required |
| Full likelihood blockers explicit. | Required |

## Human Review Requirements

- Review claim language for overstatement.
- Confirm authorship and affiliation metadata.
- Confirm licensing before upload.
- Verify all external-source citations.
- Verify no MHLM/AOIA/MDLH material leaked into LSC scientific core.
- Verify archive file list and checksums.
- Decide whether to publish as a GitHub release, Zenodo deposit, or private archival package only.
